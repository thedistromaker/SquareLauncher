New in 4.0

  • Fresh look & name. Cuboid replaces the old lime-on-slate theme.
  • Per-profile memory. Three-dot profile settings with a heap slider capped at RAM − 1024 MiB.
  • Dependency aware. Modrinth installs resolve required dependencies and never stack duplicate mods.
  • Resource packs in the marketplace, plus drag-and-drop pack import.
  • JDK downloads fixed. Adoptium Temurin replaces the dead Oracle URLs.

Removed in 4.0

  • Microsoft / msAuth sign-in is gone. The device-code flow, stored session and auth IPC have been removed; Cuboid is offline-mode only.
  • ZIP package installs are deprecated. They still work, but only require a start.py and can't be verified, updated or dependency-checked.
