# SquareLauncher
SquareLauncher is a free MC launcher that has a basic Tkinter UI.
# Setup
MacOS for now.<br>
```git clone https://github.com/thedistromaker/SquareLauncher.git```<br>
```cd SquareLauncher```<br>
```curl -fsSL https://raw.githubusercontent.com/thedistromaker/SquareLauncher/main/install.sh | sudo bash```<br>
```chown -R youruser:staff ~/SquareLauncher```<br>
```cd ~/SquareLauncher```<br>
```/Library/Frameworks/Python.framework/Versions/3.13/bin/python3 -m pip install pillow tkinterdnd2```
